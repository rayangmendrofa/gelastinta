WHAT IS REAL AND WHAT IS GAME

  • Real: the PLC program greenhouse.st runs unmodified in an IEC 61131-3 interpreter, scan by scan (50 ms), in your browser. It is the same file that passes the automated tests and runs on OpenPLC Runtime v4.
  • Model: the greenhouse — weather, air, crop water use, pump and dripper hydraulics, nutrient and pH chemistry — is a physics model. The PLC only sees it through its sensors.
  • Game: crops, varieties, health and harvest are added for this page, on an accelerated clock: one simulated minute of good daylight counts as one growing day. So are coins, levels, building, items, problems, roadblocks and achievements.
  • Upgrades: the shade net, pad-and-fan cooling, fogging and light-sum watering are functions the PLC program always has. Until you buy the hardware, their set points are parked where they never act. The canvas draws the physical plant, so a puddle or a stopped pump is what you would see on site; the panels show what the PLC's sensors say.
  • Scaling: every greenhouse you build runs its own copy of the same greenhouse.st, with no change to the program. More greenhouses means more PLC scans to compute, so the farm runs a little slower.
